# 🌐 Constantino IT — Website

The official website of **Constantino IT**, a company specialized in software development, IT consulting, cloud solutions and mobile apps.  
It's a multilingual single-page application built with **React** (and an **Angular** port), deployed on **GitHub Pages** at [constantinoit.com](https://constantinoit.com).

---

## 🚀 Features

- 🌍 **9 languages** — English, Español, Italiano, Português, Français, Deutsch, 中文, 日本語 and العربية
- 🧭 Automatic language detection from the browser/OS, with the visitor's choice remembered
- 🧩 Client-side routing with animated page transitions
- 💬 Lead chat widget on the home page, with notifications sent through **ntfy** (`cit-v2`, `with-angular`)
- ✉️ Contact form powered by **FormSubmit**
- 📱 Responsive layout with mobile navigation (sticky top menu on `cit-v2` and `with-angular`)
- 📈 Google Analytics (gtag.js)
- 🚢 One-command deploy to **GitHub Pages**

## 🧩 Getting Started

Clone the repository and pick a branch:

```bash
git clone https://github.com/ademirconstantino/cit-react.git
cd cit-react
git checkout cit-v2        # or main, with-angular
npm install
```

### ⚛️ React branches (`main`, `cit-v2`)

```bash
npm run dev       # dev server at http://localhost:5173
npm run build     # production build in dist/
npm run preview   # serve the production build locally
```

### 🅰️ Angular branch (`with-angular`)

```bash
npm start         # dev server at http://localhost:4200
npm run build     # production build in dist/cit/browser/
npm run preview   # serve the production build locally
```

## 🌍 Translations

All texts live in `public/json/cit.<lang>.json`, one file per language:

| File | Language |
| --- | --- |
| `cit.en.json` | English |
| `cit.es.json` | Español |
| `cit.it.json` | Italiano |
| `cit.pt.json` | Português |
| `cit.fr.json` | Français |
| `cit.de.json` | Deutsch |
| `cit.ch.json` | 中文 |
| `cit.jp.json` | 日本語 |
| `cit.em.json` | العربية |

To add or change a text, edit the same key in every file — e.g. `menu.home`, `contact.send_message`.

## 🚢 Deploy

The site is published to the `gh-pages` branch:

```bash
npm run deploy
```

This builds the project, copies `index.html` to `404.html` (so deep links like `/contact` work on GitHub Pages) and pushes the output with **gh-pages**.
